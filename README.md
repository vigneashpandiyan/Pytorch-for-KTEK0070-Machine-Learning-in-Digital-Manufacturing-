![Python](https://img.shields.io/badge/Python-3.x-yellow)

Welcome to the repository for the **Machine Learning in Digital Manufacturing** course! This repository is designed to guide you through the fundamental and advanced concepts of Machine Learning and Deep Learning using Python and PyTorch.

---

## 🌟 Introduction

This repository contains a series of Jupyter Notebooks for the practical labs and scripts supporting the coursework. The goal of these hands-on sessions is to bridge the gap between theoretical knowledge and practical implementation, equipping you with the skills to apply ML and DL techniques in the context of Digital Manufacturing.

## 🗂️ Organization

The coursework is logically divided into two primary series:

1. **[Python Series](./Python%20Series/)**: A thorough introduction to programming in Python, data science libraries, and core Machine Learning concepts.
2. **[PyTorch DL Series](./Pytorch%20DL/)**: Deep dive into Deep Learning architectures, building neural networks, optimization, and training models using PyTorch.
